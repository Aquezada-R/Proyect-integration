# Conceptos importantes a tener en cuenta y metodologias usadas

## Data-Driven testing
~~~
Data-Driven Testing significa:

Ejecutar un mismo caso de prueba varias veces, cambiando solo los datos de entrada (input), pero manteniendo el mismo flujo lógico.
~~~

## POM (Page object model).
~~~
fixtures como medio de almacenamiento de datos de prueba.
Pages (en la carpeta support) para seccional las paginas y los campos de las pruebas.

~~~
