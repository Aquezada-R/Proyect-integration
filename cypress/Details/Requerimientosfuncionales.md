# Requerimientos Funcionales

1. El sistema debe permitir registro y login vía API.

2. El usuario debe poder buscar libros en el catálogo.

3. El usuario debe poder agregar/eliminar libros de su biblioteca personal.

4. Las APIs deben responder en menos de 2 segundos (requisito no funcional de performance).

5. El sistema debe registrar logs de cada transacción
